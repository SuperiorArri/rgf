# RGF

RGF is a compatible alternative to OMGF (Oh My Git Flow), offering the same workflow.
(See the original repository: https://github.com/kukenc/omgf)

What the "R" in the name of this project stands for is intentionally left
to your imagination :P.

This tool will provide the same set of features as the original project mentioned earlier,
along with additional configuration options.
Being written in a cross-platform, compiled language (Rust), it will work across platforms
and will not be limited to Bash.
